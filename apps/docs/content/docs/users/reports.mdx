Open **Reports** in the sidebar. It has a dashboard and six detailed reports: **Sales**, **Leads**, **Accounts**, **Activity**, **Campaigns**, and **Users**.

## Pick a date range

Every report page has a date range at the top. Choose **Last 7 days**, **Last 30 days**, **Last 90 days**, **Year to date**, or **All time**. For other dates, click **Custom** and pick **From** and **To**. Without a choice, reports cover the last 30 days.

The range is kept in the page address, so you can bookmark or share a report with its dates.

Money values use the display currency picked in the header. See [Getting started](/docs/users/getting-started).

## Reports dashboard

The **Reports** dashboard shows key figures for the selected period: **Total Revenue**, **Pipeline Value**, **New Leads**, **Conversion Rate**, **New Contacts**, **Active Users**, **Open Tasks**, **Campaigns Sent**, **New Accounts**, and **Contracts Expiring**.

Each card shows the change against the previous period of the same length, as a percentage with an up or down arrow. Click a card to open the detailed report behind it.

## Detailed reports

| Report | What it shows |
| --- | --- |
| **Sales** | Total Revenue, Pipeline Value, Average Deal Size, Win Rate, Avg. Sales Cycle, Opportunities by Sales Stage, Opportunities by Month |
| **Leads** | Conversion Rate (leads converted to opportunities), New Leads by Month, Lead Sources, New Contacts by Month, Contacts by Account |
| **Accounts** | New Accounts by Month, Accounts by Industry, Top Accounts by Revenue, Accounts by Size |
| **Activity** | Overdue Tasks, Tasks Created vs Completed, Tasks by Assignee, Activities by Type |
| **Campaigns** | Emails Sent, Open Rate, Click Rate, Campaign Sends, Top Templates, Target List Growth |
| **Users** | Total Active Users, Active Users by Year, User Growth, Users by Role |

## Export a report

On any detailed report, click **Export CSV** or **Export PDF**. The file covers the date range you have selected.

<Callout type="info">
With the user role you cannot export the **Users** report.
</Callout>

## Save a report

To keep a date range you use often:

1. Set the range on a detailed report.
2. Click **Save**.
3. Enter a **Report Name**. Turn on **Share with team** if colleagues should see it too.
4. Click **Save**.

To load it later, open the **Saved reports...** list on the same report. Shared reports are marked "shared".

## Get a report by email

You can have a saved report emailed on a schedule.

<Steps>
<Step>
Save the report first (see above).
</Step>
<Step>
Click **Schedule** and pick the **Saved Report**.
</Step>
<Step>
Choose a **Frequency**: **Daily (9am)**, **Weekly (Monday)**, **Weekly (Friday)**, or **Monthly (1st)**.
</Step>
<Step>
Enter **Recipients** as a comma-separated list of email addresses.
</Step>
<Step>
Pick a **Format**: CSV, PDF, or **Both (CSV + PDF)**. Click **Create Schedule**.
</Step>
</Steps>

The first email goes out within about 15 minutes. After that, NextCRM sends the report again once a day (daily), 7 days (weekly), or 28 days (monthly) have passed since the last send. The report arrives as an attachment with the subject "Report: " followed by the report name.

<Callout type="warn">
There is no screen yet to list, change, or stop a schedule. Ask an admin if you need one removed.
</Callout>
