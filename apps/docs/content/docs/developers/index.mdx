This section is for developers who contribute to NextCRM, write plugins, or connect other systems and AI agents to it.

NextCRM is a single Next.js 16 App Router app with React 19, Prisma 7 on PostgreSQL with pgvector, Better Auth, Inngest for background jobs and next-intl for four UI languages. Server Components read data, server actions write it, and every entry point checks permissions through one shared library.
