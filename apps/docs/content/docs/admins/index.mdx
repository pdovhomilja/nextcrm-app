This guide is for people who host and administer NextCRM: installing it, configuring integrations, managing users, and keeping the instance backed up and up to date.

A NextCRM instance is the Next.js app plus PostgreSQL with pgvector, S3-compatible storage and Inngest. The repository's Docker Compose files run all four. Login is passwordless by email code, so plan to set up Resend early.
